# Dokan_Shop — E-Commerce Frontend

Live: **https://dokan-shop25.vercel.app** · Repo: **ENG-AHMEDHUS/Dokan_Shop**

Multi-page e-commerce frontend with category pages, cart, login / sign-up.

## ✨ Features
- Home + Men / Women / Kids / Accessories pages
- About, Contact, Login, Sign-up
- Cart logic in vanilla JS
- Responsive HTML/CSS layout

## 🛠️ Tech Stack
HTML5, CSS3, JavaScript, Vercel

## 🚀 Run locally
```bash
git clone https://github.com/ENG-AHMEDHUS/Dokan_Shop.git
cd Dokan_Shop
# just open index.html, or:
npx serve .
```

## 📁 Structure
```
index.html
mens.html / womens.html / kids.html / accessories.html
about.html / contact.html / log_in.html / sign_up.html
style/ js/ images/ webfonts/
```
